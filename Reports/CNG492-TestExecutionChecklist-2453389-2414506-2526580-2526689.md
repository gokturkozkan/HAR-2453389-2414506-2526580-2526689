# HAR Test Execution Checklist

This file maps the Test Results report cases to executable code, live evidence scripts, or hardware/manual evidence steps.

## 1. Environment

Backend setup:

```powershell
cd Hardware\RaspberryPi\HAR-backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Backend automated tests:

```powershell
cd Hardware\RaspberryPi\HAR-backend
python -m unittest discover -s tests -v
```

Unity bridge automated tests:

```powershell
cd Unity\Python
python -m unittest -v test_bridge_server.py
```

Live backend:

```powershell
cd Hardware\RaspberryPi\HAR-backend
python app.py
```

Live API evidence:

```powershell
python tools\har_api_evidence_runner.py --base-url http://localhost:3000 --out Reports\evidence\har_api_evidence.json
```

Live API evidence with real model prediction and latency:

```powershell
python tools\har_api_evidence_runner.py --base-url http://localhost:3000 --real-predict --latency-runs 50 --out Reports\evidence\har_api_evidence_real_predict.json
```

Resource evidence:

```powershell
python tools\har_resource_evidence_runner.py --process-name app.py --duration 120 --out Reports\evidence\har_resource_evidence.json
```

Unity bridge live evidence:

```powershell
cd Unity\Python
python bridge_server.py 123456
```

In another terminal:

```powershell
python tools\har_bridge_evidence_runner.py --code 123456 --label walking --out Reports\evidence\har_bridge_evidence.json
```

Offline model evaluation:

```powershell
python tools\har_model_evaluation_runner.py --csv Reports\evidence\labeled_har_windows.csv --out Reports\evidence\har_model_evaluation.json
```
